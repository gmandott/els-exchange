# hitf/

Duplicati temporanei di documenti e decisioni HITF (Human in the Field), copiati da `human-in-the-field` (repository privato, fonte di verità) per essere letti da GPT ai fini di validazione esterna.

- Non è la fonte di verità: eventuali correzioni vanno fatte nel documento originale su `human-in-the-field`, non qui.
- Cancellare i file qui presenti dopo che la validazione per cui sono stati copiati è conclusa.
- Non copiare qui dati personali, dati cliente, prezzi, credenziali, token, endpoint interni o percorsi locali — questo repository è pubblico. Rispettare in particolare il vincolo di riservatezza già in vigore per i segnali HITF (vedi `governance/hitf-operating-model.md` nel repository di origine).

Cartella vuota in attesa del primo documento da sottoporre a validazione.
