# signals/inbox

Contiene segnali leggeri appena proposti per Orchestration Practices.

Ogni segnale deve essere un singolo file Markdown, creato solo quando esiste almeno un criterio di rilevanza previsto dal modello operativo. Questa cartella non contiene bozze non sanificate, dati sensibili o evidence pack operativi.

Questo README conserva la directory nel repository e non rappresenta un segnale.
